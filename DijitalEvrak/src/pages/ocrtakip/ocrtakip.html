Notlar

Diplomatik notlarda yüksek doğruluk, tablo tanıma, çok dilli içerik ve düşük hata toleransı gerektiği için. Aşağıda teknik mimari, lisanslama modeli, entegrasyon yöntemleri, alternatif çözümler, avantaj–dezavantaj analizi gibi karar vermeni kolaylaştıracak kapsamlı bir değerlendirme bıraktım.


OCR mikroservisi modeli Nasıl çalışır? ABBYY Engine bir Windows veya Linux sunucusuna kuruluyor. Sen .NET Web API üzerinden bu Engine’e istek atıyorsun. Engine PDF/TIFF/IMG alıp OCR + Layout export ediyor (JSON, XML, TXT, PDF-A vb.). Çıktıyı MinIO/S3’e veya SQL’e işleyip uygulamana geri dönüyorsun. Avantajları Çok yüksek doğruluk oranı (%90–99 arası, belge tipine göre). Tabloları, mühürleri, imzayı, damgaları ayırma özellikleri. Çok hızlı—CPU/GPU paralelliği destekliyor. İnternet gerektirmiyor → kapalı devre ağ için ideal Bütün diplomatik dilleri destekliyor (TR, EN, FR, DE, RU, AR, FA vb.) Dezavantajları Lisans maliyeti yüksek (çekirdek sayısı + sayfa başı fiyatlandırma). Konfigürasyonu biraz teknik bilgi ister. Trial versiyonunda watermark olur.
